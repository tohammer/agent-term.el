#+TITLE: copilot-ide.el
#+OPTIONS: toc:nil num:nil

* Overview

Emacs integration for the [[https://docs.github.com/copilot/concepts/agents/about-copilot-cli][GitHub Copilot CLI]]. Runs =copilot= in a terminal buffer (=vterm= or =eat=) inside a side window. Optionally exposes an HTTP MCP server so Copilot can call Emacs functions (xref, imenu, tree-sitter) during a session.

Heavily inspired by [[https://github.com/manzaltu/claude-code-ide.el][claude-code-ide.el]] by manzaltu.

* Requirements

- Emacs 28.1+
- [[https://docs.github.com/copilot/concepts/agents/about-copilot-cli][GitHub Copilot CLI]] (=copilot= on =PATH=)
- =vterm= or =eat= (terminal backend)
- =transient= >= 0.9.0
- =web-server= (only for MCP tools server)

* Installation

** use-package (Emacs 29+)

#+begin_src emacs-lisp
(use-package copilot-ide
  :vc (:url "https://github.com/tohammer/copilot-ide.el")
  :commands (copilot-ide copilot-ide-menu))
#+end_src

* Usage

| Command                          | Description                                      |
|----------------------------------+--------------------------------------------------|
| =M-x copilot-ide=                | Start or toggle session for current project      |
| =M-x copilot-ide-stop=           | Stop the current session                         |
| =M-x copilot-ide-toggle=         | Toggle the session window                        |
| =M-x copilot-ide-toggle-recent=  | Toggle the most recently used session            |
| =M-x copilot-ide-switch-to-buffer= | Focus the Copilot terminal buffer              |
| =M-x copilot-ide-list-sessions=  | Pick from all running sessions                   |
| =M-x copilot-ide-send-prompt=    | Send a prompt from the minibuffer                |
| =M-x copilot-ide-resume=         | Resume a previous session (optional session ID)  |
| =M-x copilot-ide-check-status=   | Check CLI availability and version               |
| =M-x copilot-ide-menu=           | Open the transient menu                          |

* Configuration

** Basic

#+begin_src emacs-lisp
(use-package copilot-ide
  :commands (copilot-ide copilot-ide-menu)
  :bind ("C-c o" . copilot-ide-menu))
#+end_src

** With Emacs MCP tools

Exposes xref, imenu, tree-sitter, and project info as MCP tools to Copilot:

#+begin_src emacs-lisp
(use-package copilot-ide
  :config
  (copilot-ide-emacs-tools-setup))
#+end_src

** Custom MCP tools

#+begin_src emacs-lisp
(copilot-ide-make-tool
 :name "my_search"
 :function #'my-search-fn
 :description "Search in project"
 :args '((:name "query" :type string :description "Search query")))
#+end_src

* Customization

** Session / window

| Variable                               | Default    | Description                                      |
|----------------------------------------+------------+--------------------------------------------------|
| =copilot-ide-cli-path=                 | ="copilot"= | Path to the Copilot CLI executable               |
| =copilot-ide-cli-extra-flags=          | =""=       | Extra flags passed to =copilot= at launch        |
| =copilot-ide-terminal-backend=         | ='vterm=   | Terminal backend: ='vterm= or ='eat=             |
| =copilot-ide-window-side=              | ='right=   | Side for the Copilot window                      |
| =copilot-ide-window-width=             | =100=      | Width of the side window (left/right sides)      |
| =copilot-ide-window-height=            | =20=       | Height of the side window (top/bottom sides)     |
| =copilot-ide-focus-on-open=            | =t=        | Focus the window when opened                     |
| =copilot-ide-use-side-window=          | =t=        | Use a dedicated side window                      |
| =copilot-ide-show-modeline=            | =t=        | Show the mode line in the Copilot buffer         |
| =copilot-ide-enable-mcp-server=        | =nil=      | Enable the HTTP MCP tools server                 |
| =copilot-ide-mcp-server-port=          | =nil=      | Fixed HTTP server port (nil = auto-assign)       |

** MCP tool filtering

| Variable                               | CLI flag               | Description                                      |
|----------------------------------------+------------------------+--------------------------------------------------|
| =copilot-ide-mcp-available-tools=      | =--available-tools=    | Whitelist specific tools or servers              |
| =copilot-ide-mcp-excluded-tools=       | =--excluded-tools=     | Blacklist specific tools or servers              |
| =copilot-ide-mcp-allow-tools=          | =--allow-tool=         | Auto-approve (no confirmation prompt)            |
| =copilot-ide-mcp-deny-tools=           | =--deny-tool=          | Always deny (takes precedence over allow)        |

Each accepts a list of strings in the form ="ServerName"= (all tools) or ="ServerName(tool_name)"= (specific tool).

* Debugging

(setq copilot-ide-debug t)

#+end_src
