* Overview

=copilot-cli.el= integrates the [[https://docs.github.com/copilot/concepts/agents/about-copilot-cli][GitHub Copilot CLI]] into Emacs. It runs
=copilot= in a terminal buffer (=vterm= or =eat=), displayed in a configurable
side window, and optionally connects an HTTP MCP server so Copilot can call
Emacs functions such as xref, imenu, and tree-sitter directly.

** Features

- Project-aware session management (one session per project root)
- Terminal integration with full color support via =vterm= or =eat=
- Optional HTTP MCP tools server exposing Emacs functionality to Copilot
- Extensible: register any Elisp function as an MCP tool with =copilot-cli-make-tool=
- Transient menu for quick access to all commands
- Multiple concurrent sessions (one per project)

** What This Package Does NOT Do

The following features from =claude-code-ide.el= are absent because they
require Claude Code CLI's proprietary bidirectional WebSocket IDE mode, which
Copilot CLI does not have:

- Live cursor/selection push to Copilot (=selection_changed= notifications)
- Copilot-initiated file opening (=openFile= tool)
- Copilot-initiated ediff sessions (=openDiff= / =closeTab= tools)
- Elisp evaluation from Copilot (=executeCode= tool)
- Flycheck/Flymake diagnostics on demand (=getDiagnostics= tool)
- Inline context injection (=at_mentioned= notifications)

See [[file:copilot-port.md][copilot-port.md]] for a detailed analysis of what is and is not portable.

* Requirements

- Emacs 28.1 or later
- [[https://docs.github.com/copilot/concepts/agents/about-copilot-cli][GitHub Copilot CLI]] (=copilot= on =PATH=, with an active Copilot subscription)
- One of:
  - [[https://github.com/akermu/emacs-libvterm][vterm]] (recommended)
  - [[https://codeberg.org/akib/emacs-eat][eat]]
- =transient= ≥ 0.9.0 (usually bundled with Emacs 29+)
- =web-server= (for MCP tools — install via =M-x package-install RET web-server=)

* Installation

** Manual

Clone the repository and add to your load path:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/copilot-cli.el/")
(require 'copilot-cli)
#+end_src

** With use-package

#+begin_src emacs-lisp
(use-package copilot-cli
  :load-path "/path/to/copilot-cli.el/"
  :commands (copilot-cli copilot-cli-menu))
#+end_src

* Basic Usage

| Command                       | Description                                       |
|-------------------------------+---------------------------------------------------|
| =M-x copilot-cli=             | Start a session (or toggle the window)            |
| =M-x copilot-cli-stop=        | Stop the session for the current project          |
| =M-x copilot-cli-switch-to-buffer= | Focus the Copilot buffer                     |
| =M-x copilot-cli-list-sessions= | Pick from all running sessions                  |
| =M-x copilot-cli-send-prompt= | Send a prompt from the minibuffer                 |
| =M-x copilot-cli-send-escape= | Send Escape to the Copilot terminal               |
| =M-x copilot-cli-insert-newline= | Insert a newline in the Copilot prompt          |
| =M-x copilot-cli-toggle=      | Toggle the Copilot window for the current project |
| =M-x copilot-cli-toggle-recent= | Toggle the most recently used session           |
| =M-x copilot-cli-check-status= | Check CLI availability and version               |
| =M-x copilot-cli-menu=        | Open the transient menu                           |

Within the terminal buffer:

| Key         | Description            |
|-------------+------------------------|
| =S-<return>= | Insert newline in prompt |
| =C-<escape>= | Send Escape            |

* Configuration

** Minimal setup (terminal only)

#+begin_src emacs-lisp
(require 'copilot-cli)

;; Optional: bind the transient menu
(global-set-key (kbd "C-c o") #'copilot-cli-menu)
#+end_src

** With Emacs MCP tools

Enable this to let Copilot call xref, imenu, tree-sitter, and project
information from inside your Emacs session:

#+begin_src emacs-lisp
(require 'copilot-cli)
(copilot-cli-emacs-tools-setup)  ; enables MCP server + registers all tools

(global-set-key (kbd "C-c o") #'copilot-cli-menu)
#+end_src

Copilot CLI will receive the MCP server URL via =--mcp-config= at startup.

** Adding custom MCP tools

Any Elisp function can be exposed as an MCP tool:

#+begin_src emacs-lisp
(copilot-cli-make-tool
 :name "my_custom_search"
 :function #'my-search-function
 :description "Search something in the project"
 :args '((:name "query"
                :type string
                :description "The search query")))
#+end_src

* Customization

| Variable                         | Default    | Description                                 |
|----------------------------------+------------+---------------------------------------------|
| =copilot-cli-cli-path=           | ="copilot"= | Path to the Copilot CLI executable          |
| =copilot-cli-terminal-backend=   | ='vterm=   | Terminal backend: ='vterm= or ='eat=        |
| =copilot-cli-window-side=        | ='right=   | Side for the Copilot window                 |
| =copilot-cli-window-width=       | =100=      | Width of the side window (left/right)       |
| =copilot-cli-window-height=      | =20=       | Height of the side window (top/bottom)      |
| =copilot-cli-focus-on-open=      | =t=        | Focus the window when opened                |
| =copilot-cli-use-side-window=    | =t=        | Use a dedicated side window                 |
| =copilot-cli-cli-extra-flags=    | =""=       | Extra flags passed to =copilot= at launch   |
| =copilot-cli-enable-mcp-server=  | =nil=      | Enable the HTTP MCP tools server            |
| =copilot-cli-mcp-server-port=    | =nil=      | Fixed HTTP server port (nil = auto)         |
| =copilot-cli-debug=              | =nil=      | Enable Emacs-side debug logging             |

* Architecture

#+begin_example
┌─────────────────────────────────────────────────────────┐
│ Emacs                                                   │
│                                                         │
│  ┌──────────────────┐    side    ┌───────────────────┐  │
│  │  Source buffers  │   window   │  Copilot terminal │  │
│  │  (your code)     │           │  (vterm / eat)    │  │
│  └──────────────────┘           └───────────────────┘  │
│                                          │              │
│  ┌──────────────────────────────────┐    │              │
│  │  HTTP MCP Tools Server           │◄───┘              │
│  │  /mcp/{session-id}               │  --mcp-config     │
│  │                                  │                   │
│  │  Tools:                          │                   │
│  │  • copilot_cli_xref_find_references                  │
│  │  • copilot_cli_xref_find_apropos                     │
│  │  • copilot_cli_project_info                          │
│  │  • copilot_cli_imenu_list_symbols                    │
│  │  • copilot_cli_treesit_info                          │
│  └──────────────────────────────────┘                   │
└─────────────────────────────────────────────────────────┘
#+end_example

Copilot CLI connects to the HTTP MCP server as an MCP client whenever it
needs to invoke an Emacs tool.  Session IDs in the URL path (=/mcp/{id}=)
allow multiple concurrent sessions to each get their own Emacs buffer
context.

The last active buffer per session is tracked automatically via
=post-command-hook=, so MCP tools always operate in the correct project
context.

* MCP Tools Reference

| Tool name                          | Description                                       |
|------------------------------------+---------------------------------------------------|
| =copilot_cli_xref_find_references= | Find usages of an identifier via xref/LSP         |
| =copilot_cli_xref_find_apropos=    | Search symbols by pattern via xref/LSP            |
| =copilot_cli_project_info=         | Project directory, active buffer, file count      |
| =copilot_cli_imenu_list_symbols=   | All functions/classes/vars in a file with lines   |
| =copilot_cli_treesit_info=         | Tree-sitter AST node info for a file or position  |

* Debugging

Enable debug logging to trace MCP communication:

#+begin_src emacs-lisp
(setq copilot-cli-debug t)
;; View log:
(copilot-cli-show-debug)
;; Clear log:
(copilot-cli-clear-debug)
#+end_src

Or toggle it via the transient menu: =M-x copilot-cli-menu= → =d= → =d=.
